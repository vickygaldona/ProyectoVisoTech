## Sobre el proyecto

**VisoTech** es el sitio web de nuestro emprendimiento de desarrollo web. Está pensado para presentar los servicios que ofrecemos, mostrar ejemplos de trabajos reales y facilitar que cualquier persona nos contacte por WhatsApp para pedir un presupuesto.

Diseñamos webs visuales, modernas y adaptadas a cada negocio o proyecto, con animaciones cuidadas y pensadas para verse bien en el celular.

### Servicios

- **Landing page para negocios:** una página clara y visual que presenta el negocio y lleva a la consulta.
- **Invitación digital para eventos:** invitaciones web con diseño propio para cumpleaños, bautismos, casamientos y otros eventos.
- **Carta o catálogo digital:** productos o menú en una página visual, fácil de abrir desde el celular.
- **Proyecto personalizado:** un sitio a medida de la identidad y las necesidades de cada cliente.

Cada servicio tiene su propuesta en PDF, disponible desde el sitio.

### Qué incluye el sitio

- Presentación de los servicios y buscador para elegir qué proyecto conviene.
- Portfolio con demos de proyectos reales, en un carrusel de tarjetas.
- Contacto directo por WhatsApp con cada integrante del equipo.
- Páginas de política de privacidad y términos y condiciones.

### Tecnologías

- [Next.js](https://nextjs.org/) (App Router) y [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) para las animaciones
- [Lucide](https://lucide.dev/) para los íconos
